## 4.5 追加实验:选择性结合(2026-07-03,用户提问"因子不能结合吗")

在旧 22 因子基础上**挑着加**新因子,同窗(2025-01-01~2026-07-01)等权合成
topk15 周频回测:

- 组合A:旧22 + amihud_amt20 + bp → RankIC +0.0698(略升),但扣成本
  年化 **−1.9%**、回撤 −44.1%(灾难)
- 组合B:旧22 + turn_std20 + amihud_amt20 → RankIC +0.0706,年化 **+13.0%**、
  回撤 −40.9%(仍远差于旧集单干)
- 组合C:旧22 + 四个新因子 → 相关性去重后与A同集,结果同A
- 基准:旧22单干 → RankIC +0.0685,年化 **+28.9%**、回撤 −32.3%

**结论:在"等权平均+TopkDropout 只买最顶部"框架下,任何往里掺新因子的
结合都变差**,即使截面 RankIC 反而略升。机制:amihud/低换手把 Top15 推向
更小更难交易的票,头部桶收益被摧毁(A 组年化直接转负)。RankIC 是全截面
平均,组合只吃头部——两者脱钩是本次最重要的方法论教训。

**结合若要成立,需换框架**(均为另立实验,不动生产):
1. **学习权重**:LightGBM 直接在 48 因子上学非线性组合(ml_pipeline 已有
   基建,把 Alpha158 换成手工因子面板);
2. **过滤器用法**:新因子不进打分,只做否决——如剔除 amihud 最差档
   (太难交易)/换手波动最高档后再按旧复合分选;
3. **20日慢线**:amihud+低换手按 h20 重新合成、持有期20日单独成线。
